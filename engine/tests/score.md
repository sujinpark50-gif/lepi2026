# 5단계 검증 점수 (run 1, claude-opus-5-5)

- 입력: `run1_opus.json`(13개), `run1_opus_log.txt` · 판정 결과: `run1_opus_judge.json` (판정 API 12회, READY만)
- `judge.py`는 v2 JSON 모양 그대로 돌았다. **수정 없음.**
- 통과 기준: 지어낸 사실 0 + 규칙 위반 0 + 감성 ≤ 1/3 + 품질 글 하나 최저선(≥15, 항목 1점 이하 없음).
- 감성 비율: 끝맺음이 약속/인사일 때만 뺀다. `~보세요` 권유형 끝은 본문으로 셌다(단풍 네일만 결과가 바뀜).
- 품질 % = (총점 − 11.3) / (21.9 − 11.3). 0% = 기계 글, 100% = 파사드패턴.

## 0. 보정(calibration)

- 승인된 확정본이 없어 **확정본으로 판정기를 보정하지 못했다.**
- 대신 판정기가 말이 되는지만 확인했다. v1 3개 → v2 같은 메모 3개: 쥐꼬리 16→17, 밀짚 20→16, 닉스고 17→21 (평균 17.7→18.0).
  순위도 상식과 맞다. 판매자 결정이 분명한 무화과는 28점, 상품이 빠진 선운사는 16점(쓸모 1)이다.
- 한계: 판정기는 사실 검사를 하지 않는다. "저희 가게"를 지어낸 반려돌도 27점, 부정을 빠뜨린 머그컵도 27점을 받았다. 그래서 품질 점수와 규칙 통과는 따로 본다.

## 2. 요약

- **통과 7/13** (목표 ≥ 11) → **미달**.
- **평균 품질 21.2/30 = 93%** (READY 12개, 목표 18.7 = 70%) → **달성**. 최저선 미달 1/12(선운사).
- 품질 점수와 규칙 통과가 따로 논다. 품질 상위 3개 중 2개(반려돌, 머그컵)는 규칙 위반으로 떨어졌다.
- **v1 기준선과 비교 (같은 메모 9개)**
  - 시간: v1 평균 14.2초(최대 19.6) → v2 18.0초(최대 30.4). 13개 전체 평균은 18.3초다.
  - 호출: v1 17회(1.89회/개) → v2 22회(2.44회/개). 재작성은 13개 중 6개였다.
- **비용** (로그 기준, 1달러 = 1400원): 평균 72.9원, 최대 122.8원(닉스고, 재작성 포함 3회 호출). 재작성이 없으면 37~82원, 있으면 84~123원이다.
- 재작성이 오히려 글을 망친 예가 있다. 쥐꼬리는 재작성 뒤 핵심 장면("흔들면 흥분하면서")이 제목으로만 밀려났고, 본문 끝맺음도 지워졌다.
- **가장 약한 글: 선운사 소원의 종** (16점, 쓸모 1).
  - "거기 걸린 선운사 종은…" 문장이 UNGROUNDED로 지워졌다. 그 결과 본문에 상품도 가격(만원)도 없는 방문 일기만 남았다.
  - 남은 문장 "바람에 풍경처럼 흔들리면서"는 주어가 없다.
  - 판매자 시점도 아니다(DEMO).

## 4. 고칠 순서 (효과 큰 순)

1. **DEMO_SELLER 시점 변환** (설계+프롬프트). 3개 실패를 한 번에 고친다. analyzer.md DEMO 절과 writer.md를 고치고 v2-design.md에 규칙을 적는다.
2. **삭제 오탐 줄이기** (코드, api/index.py).
   - `_seller_ungrounded`의 1글자 앞말 처리
   - 표기 변형 정규화
   - 유일한 fact 문장은 삭제 대신 재작성
   - NO_PRODUCT_BODY 검사 추가

   단풍·선운사 실패와 딸기·머그컵·쥐꼬리의 품질 손실을 줄인다.
3. **권유형 끝맺음** (코드+프롬프트). `~보세요` 권유는 invite로 보고 비율에 넣는다. writer.md 금지 예시에도 추가한다.
4. **"저희 가게" 지어내기 검사** (코드). B 표에 추가하고 writer.md 예시를 고친다.
5. **부정·불확실 표지 보존** (프롬프트). analyzer.md에 표시를 달고 writer.md에 규칙을 넣는다.
